# Шрифт для картинок шаринга

`Onest-SemiBold.ttf` — статичный инстанс Onest, OFL-1.1, тот же шрифт, что и на сайте.

Лежит здесь, а не в `public/fonts/`, потому что в браузер он не уезжает: его читает
`src/lib/og.ts` на сборке, чтобы нарисовать OG-картинку кейса. В `public/` он стал бы
57 КБ, которые никто никогда не скачает, но которые лежат в `dist/`.

Формат — TrueType, а не woff2: растеризатор картинок распаковывать brotli не умеет,
ему нужен статичный файл с готовыми таблицами глифов.
