# Мастер-кадры кейсов

Одна папка на кейс, имя папки — слаг: `shots/<slug>/`. Русский документ кейса
ссылается на файл относительным путём `../shots/<slug>/card@2x.webp`; английский
перевод повторяет только `alt`, потому что файл у пары общий.

```
shots/
  th-neva-beauty/
    card@2x.webp        1600×1000   обложка карточки
    cover@2x.webp       1920×960    обложка страницы разбора
    01-prices.webp      1600×1000   доказательство: файл-источник цен
    og.webp             1200×630    превью в мессенджерах
```

Размеры, вес и правила съёмки — `docs/CONTENT-CASES.md §3`. Их сверяет
`tests/check-content.mjs` на каждой сборке: файл не того размера или тяжелее
400 КБ не доедет до прода.

`@2x` в имени — мастер двойной плотности. Версию 1× режет сборка, руками
её не делаем и в репозиторий не кладём.
