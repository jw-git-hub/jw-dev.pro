- Решение: стили только глобальными файлами, без `<style>` в компонентах — гайд написан
  как глобальный CSS, и из HTML уходят служебные `data-astro-cid-*`.

  вшивает мелкие стили в разметку и ломает CSP. Второе — в Astro 7 по умолчанию `'jsx'`,
  где пробел между строчными элементами съедается.

  `--legacy-peer-deps` не стал, доступность проверяет `html-validate:a11y` на собранном HTML.
