## 2026-08-22 · Фаза 3 — фон и движение

- Сделано: аврора, вуаль, свет за курсором, канвас-граф с якорями `data-nx`, импульсами
  и демпфированием, механика акцента секции, появление `.rv`. Заодно поставлен
  `@astrojs/check`: без него ворота `check:astro` молча проходили, не проверив ничего.
- Решение: пары цветов акцента живут в `accent.css`, скрипт переносит на `<html>` только имя.
  Значений цвета в JS нет вовсе — граф снимает палитру с `:root` при старте.
- Решение: у пятен ауроры нет `filter: blur(100px)` из §1 — в макете его тоже нет. Мягкость
  даёт сам градиент, а размытие во весь экран отняло бы у графа кадры.
- Грабли: `inset: 0` не растягивает `<canvas>`. Замещаемому элементу при `width: auto`
  браузер оставляет размер растра и правый упор игнорирует; нужны проценты.
- Грабли: предохранитель `.rv` из макета через 1.2 с гасит анимацию на всей остальной
  странице. Снимаем его первым же ответом наблюдателя и не заводим в фоновой вкладке.

## 2026-08-21 · Фаза 0 — репозиторий и рельсы

- Сделано: Astro 7.2.4, структура папок, i18n-каркас (EN на `/`, RU на `/ru/`), знак `>jw_`,
  заглушка на обоих языках, линтеры, шесть проверок в `npm run check`, Nginx с CSP, CI.
- Решение: стили только глобальными файлами, без `<style>` в компонентах — гайд написан
  как глобальный CSS, и из HTML уходят служебные `data-astro-cid-*`.
- Решение: `build.inlineStylesheets: 'never'` и `compressHTML: true`. Первое — иначе Astro
  вшивает мелкие стили в разметку и ломает CSP. Второе — в Astro 7 по умолчанию `'jsx'`,
  где пробел между строчными элементами съедается.
- Грабли: `eslint-plugin-jsx-a11y` не поддерживает ESLint 10. Ломать дерево
  `--legacy-peer-deps` не стал, доступность проверяет `html-validate:a11y` на собранном HTML.
- Грабли: линтер нашёл мёртвый `|| '/'` в `localizePath` — шаблонная строка всегда истинна.
- Заблокировано: домен не куплен, доступа к серверу нет. Выкат ждёт и то и другое.
